Fix: the legacy-addon startup guard queried `GET /info` — the Supervisor ROOT endpoint, which does not include the installed add-ons list — so it silently passed while `jethub-mqtt-io` was running. The guard now asks `GET /addons/jethub-mqtt-io/info` directly (with `GET /supervisor/info` as fallback) and logs the reason for every skip. Everything else is unchanged from 0.1.0-rc.2.
