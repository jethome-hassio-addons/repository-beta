Docs: clarified the failure semantics of the legacy-add-on startup refusal. The add-on already exits non-zero on purpose, which lands it in the Supervisor **error** state (red). A restart loop only happens when the add-on **Watchdog** toggle is enabled — the watchdog retries a failed start up to 5 times before giving up; no exit code can prevent that. Keep the watchdog off for this add-on (documented now as well).
